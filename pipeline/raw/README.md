# 元データ取得スクリプト置き場

印旛沼流域の解析に使う元データ（DEM、土地利用、行政界など）を
取得・ダウンロードするスクリプトをここに置く。

データ本体は `data/raw/` に保存する想定だが、Git管理外（.gitignore）。
再現性のため、取得元URLと手順は必ずスクリプト内にコメントで残すこと。

## 想定データソース例

- 国土地理院 基盤地図情報（DEM）: https://fgd.gsi.go.jp/download/
- 国土数値情報（流域界・行政界・土地利用など）: https://nlftp.mlit.go.jp/ksj/
- 印旛沼流域の境界: 千葉県または国交省関東地方整備局公開データ
